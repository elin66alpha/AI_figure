AI_figure 板子 远程诊断 / 自检 操作说明
========================================

全程只需要：双击文件、按屏幕上的黄色文字操作、按回车、把结果文件发回来。
不需要输入任何命令。


准备
----
1. 把收到的“自检包”文件夹放到桌面。
   如果收到的是压缩包，先“解压”到桌面（右键 → 全部解压缩），不要在压缩包里直接双击运行。
2. 准备一根能传数据的 USB-C 线（最好是之前能看到 COM 口的那根）。
3. 关掉电脑上所有串口软件和烧录软件（串口助手、Arduino、
   flash_download_tool 等）。
4. 准备一把镊子（金属的）。平时用不上，只有程序提示时才用它短接两个焊盘。
5. 板子先不要接电池。


认识 3 个测试焊盘（只有程序提示时才用）
------------------------------------
在板子背面（有 USB-C 口的那一面）。
板上没有印字，靠位置找：

  * 先确定“顶边”：USB-C 口离哪条短边更远，那条短边就是顶边（天线那头）。
  * 把顶边朝上放好，看左边缘靠上的位置，有竖着排成一列的 3 个小方焊盘
    （每个约 1.6 mm 见方，间距约 3 mm，第一个离顶边约 2 mm）。
    它们是裸露的方形铜焊盘，比旁边的小电阻、小电容明显大，上面没有焊元件。

        ┌────────────────────┐  ← 顶边（天线那头）
        │ ■ TP1  EN   不要碰  │
        │ ■ TP2  GND          │
        │ ■ TP3  BOOT         │
        │                    │
        │                    │
        │      [USB-C 口]     │
        │                    │
        └────────────────────┘
              （背面，顶边朝上）

  需要短接时，是用镊子同时碰住 中间的 TP2 和 最下面的 TP3：
  先拔掉 USB 线，镊子按住两个焊盘不松，插上 USB 线，等 2 秒再松开镊子。
  一只手不方便可以请同事帮忙插线。


第一项：硬件自检（不需要网络）
----------------------------
测 LED、喇叭、按键、麦克风、电池电压和 USB 检测。全程约 3 分钟。
1. 喇叭和按键的线要已经焊好。接了电池，电池那一项才会判定；没接会显示“不判定”。
2. 双击 “1-自检.bat”。
   如果弹出蓝色的“Windows 已保护你的电脑”，点“更多信息” → “仍要运行”。
3. 程序会先把自检程序刷进板子，然后一项一项提示你：
   看 LED、听喇叭、按按键、对着麦克风说话。看到黄色文字时，照着做，做完按回车。
4. 如果程序说“自动方式刷不进去”，会让你用镊子短接 TP2 和 TP3（见上面），照屏幕上的步骤做。
5. 有些问题需要你回答：看到/听到了就输入 y，没有就输入 n，然后按回车。
6. 结束后会自动打开一个文件夹，并选中一个名字像
   “自检结果_20261024_135320.txt” 的文件。把这个 txt 文件原样发回来，不用看懂内容。


第二项：诊断（只在自检连不上板子、刷不进去时做）
--------------------------------------------
1. 双击 “2-诊断.bat”，按黄色文字操作，全程约 1 分钟。
2. 结束后同样会选中一个 “诊断结果_xxxx.txt”，把它发回来。


遇到问题
--------
* 窗口一闪就没了：把整个窗口截图发回来；或者告诉我们解压到了哪里。
* 窗口里出现红色文字：没关系，程序会继续往下走，最后一样会生成结果文件。
* 程序说找不到板子、让你操作时：打开“设备管理器” → “端口(COM 和 LPT)”，
  看板子是 COM 几（拔掉线会消失的那个），只输入数字后按回车。
* 任何时候拿不准，就截图发回来，不要自己改设置。
