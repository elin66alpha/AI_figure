# EasyEDA 初级常见问题与界面排障

本页用于处理嘉立创 EDA 专业版里常见的“看起来坏了、实际是显示、选择过滤、库更新或操作流程问题”。
它是排障速查，不替代 `sch check`、`pcb check`、DRC、实时制造规则和保存重开后的事实回读。

## 使用原则

1. 先判断问题属于 **显示/选择状态、库与器件绑定、电气连接、PCB 几何、工程管理** 中哪一类，再修改。
2. 显示隐藏不等于数据删除；删除、重放器件、重绑封装前仍遵守 inspect-before-mutate 和确认门。
3. 符号外观变化不等于封装或引脚关系变化。先核对 device、pin number、footprint 和 pin→net，再决定是否替换。
4. 网络匹配是精确字符串匹配；重点排查 `5/S`、`0/O`、空格、大小写及遗漏标签。
5. UI 修复后仍用 typed read/check/DRC 验证结果，不以画面观感代替电气判定。

## 原理图、器件与网络

### 库更新后 Type-C 等符号外观变化

- 官方库可能合并或重画部分符号引脚，而封装保持一致。
- 先对比引脚编号、封装焊盘和 device 绑定；若拓扑一致，可继续使用新版符号，不必为了外观还原旧符号。
- 按键等四脚器件尤其要核对常开触点对应的真实 pin number。库更新可能把触发脚从 `3/4` 调整为 `1/2`；只改图形外观不会改变电气连接。

### 修改符号后封装丢失

- 不要把“只应用选中对象”与错误的器件绑定选项混用。
- 优先应用到整个工程并保留 device/footprint 绑定；若绑定已经损坏，删除并从正确 device 重新放置，再恢复位号和网络。
- 重放或替换后必须核对 pin→net，并跑 `sch check`/DRC。

### 单网络、多网络或网络不匹配提示

- 检查所有相关导线和网络标签是否完全同名，特别检查 `5/S`、`0/O` 等视觉近似字符。
- 多网络名称异常且无法定位时，可在保留拓扑证据后删除相关短导线与标签并重新放置，然后重新检查。
- 默认一次选中整个网络/焊盘对，或无法选中单段导线时，检查右侧选择过滤器，取消“网络/焊盘对”的整体选择。

### GND/全局网络名的显示

- GND 等全局网络名可以只隐藏属性值，不必删除网络标志。
- 在“设置 → 属性 → 全局网络名”调整名称/属性值显示；显示状态不改变电气网络。

### 器件无法放置或放置选项变灰

- 检查“库 → 工程库”中是否存在损坏或冲突的器件记录。
- 若画布仍引用该工程库器件，先 inspect 并安全移除实例，再删除冲突库记录，最后从正确库重新放置。

### 位号显示 `?` 或不自动分配

- 在“设置 → 通用”检查位号分配策略，可尝试“从空缺分配位号”。
- 不要只凭 UI 修位号；用 `sch list`/`pcb list` 回读，并在 sch→PCB 同步后检查占位位号。PCB 已出现 `U?`/`C?` 时参见 `pcb-layout.md` 的 `pcb sync-designators`。

## PCB 显示、选择与属性

### 丝印、位号或其他属性无法移动

- `Shift+S` 会切换激活层亮度；隐藏或变灰图层上的对象可能无法正常选择。循环切回正常显示。
- 检查右侧选择过滤器是否取消了该对象类型。
- 器件属性只控制显示时，不要改写其语义内容；按键功能名应另放普通文本，不要篡改器件原始丝印属性。

### 隐藏 PCB 丝印

- 通过 typed 属性/文本接口取消“显示”，必要时才删除独立文本；接口缺失时标 `unsupported`。
- 区分“隐藏属性”和“删除图元”；操作后用对象列表回读确认实际状态。

### 板子看起来镜像或反转

- 先检查是否启用了“视图 → 翻转板子”。恢复视图后再判断器件层面是否真的放反，不要因视图镜像直接修改设计。

### 铺铜与填充区域混淆

- 在右侧属性中确认对象类型；需要固定实心铜形状时使用 net-bound 填充区域，需要自动避让和重建时使用铺铜。
- typed 工作流分别参见 `pcb fill` 与 pour 相关命令；转换或重建后 `doc reload` 再检查。

## 过孔、铺铜与机械规则

### 过孔放置报错

- 确认过孔网络与所在填充/铺铜网络一致。
- 过孔不能重叠；即使同网，多个过孔放在同一坐标也应视为错误。
- 根据结构化报错定位冲突对象，不要在同一点反复点击重试。

### GND 缝合过孔是否必须

- 目的不是“凑数量”，而是连接地铜并缩短高频/输入输出回流路径。
- 若整板 GND 已可靠连通，不放额外过孔不一定报错；仍应结合回流路径、层间地连续性和 EMI 判断位置。

### 晶振区域禁铜

- 通常至少禁止晶振所在信号层铺铜，并根据器件/参考设计决定是否扩展到其他层。
- 不要把该经验误套到 RF 天线：RF/天线 keepout 仍遵守顶层铁律，覆盖所有铜层。

### 电源线识别

- 从原理图的电源符号、网络角色、负载电流和电源路径判断，不要只凭网络名或线条粗细。
- 无法确定时先标为待确认，不能据“大概像电源”直接套线宽或铺铜规则。

### 非金属化槽与板边距离

- 入门经验值：非金属化槽宽不要小于 `0.8 mm`，建议大于 `1.0 mm`；槽到板边建议不小于 `1.5 mm`；长度超过 `10 mm` 时可按至少 `3 mm` 板边距离预留。
- 这些是培训材料中的可制造性建议，不是永恒的下单规则。最终以当前板厂能力、订单工艺、实时 DRC 和 `fab-rules-jlcpcb.json` 的制造地板为准，取更严格者。

### 排针方向与丝印

- PCB 排针方向应与原理图连接定义一致；即使杜邦线可补偿，也必须保证 pin 1 和逐脚功能能一一对应。
- 在接口旁增加不会被装配遮挡的功能丝印，并检查连接器朝向。

## 规则导入与工程管理

### 从原理图导入后 PCB 设计规则丢失

- 导入变更时不要无意勾选“包含设计规则、过滤”；该选项可能用原理图侧配置替换 PCB 已有规则。
- 导入前 inspect/导出当前规则，导入后回读规则并运行 DRC；不要等布线结束才发现规则被覆盖。

### 无法创建工程

- 检查工程链接/slug 是否重复或过短，换成唯一且满足长度要求的链接。

### 工程图纸、名称与本地保存

- 新工程没有图纸：通过 typed 图纸设置接口写入系统模板；接口未实现时标 `unsupported`，不在属性面板补做。本 skill 自动化流程默认 A4，并遵守“无图纸不摆放/布线”。
- 修改工程名称：在工程目录上进入编辑并保存。
- 保存至本地：使用“文件 → 另存为 → 工程另存为本地”，后续可重新导入。导出不替代阶段 `save` 检查点。
- PDF/Excel 打开乱码通常是本机查看器兼容问题，可换查看器交叉验证，避免误判源文件损坏。

## 浏览器与培训/考试专属问题

### Web 编辑器重开后持续显示加载动画

- 这类现象可能没有错误弹窗；先区分“页面还在加载”和“文档已经可读”，不要只看 URL 或活动 UUID。
- 停止循环执行 `doc reload` 和现场写入，记录错误并修复 typed reload/open；禁止刷新浏览器或从工程树手工恢复。
- 随后运行与目标类型匹配的 typed read（例如 `pcb list --include-bbox` 或 `sch list --include-pins`）；
  能读到实际对象才算恢复。若 UUID 已切换但对象读取仍超时，继续按加载失败记录。
- 不清站点数据或 IndexedDB；这会同时移除连接器和登录态，且不能证明工程数据有问题。

以下规则只用于相应在线培训或考试环境，不应影响普通生产设计：

- 没有倒计时：确认是否按考试说明进入指定团队、点击开始考试并从规定入口创建工程。
- 考试链接打不开：先刷新或切换网络；仍失败再记录错误信息，不要据此修改工程。
- Agent 不使用右键、拖动或其他鼠标手势操作 EDA 画布；相关现场步骤保持未执行。
- 截止前最后一分钟继续修改可能因网络或截止时间导致保存/提交失败；应提前保存并留出提交确认时间。
- 考后工程与本地观感不一致时，先核对最后一次成功保存/提交时间和提交回执。

## 快速分流表

| 现象 | 先查 | 再验证 |
|---|---|---|
| 符号长得不一样 | 库版本、pin number、footprint | pin→net、`sch check` |
| 选中整网/选不中单线 | 选择过滤器中的网络/焊盘对 | 对象列表与网络列表 |
| 丝印/属性不见或不能动 | `Shift+S`、层显示、对象过滤 | primitive 是否仍存在 |
| 过孔报错 | 同网、坐标重叠、铜区网络 | `pcb check`/DRC |
| 导入后规则变化 | “包含设计规则、过滤”选项 | 规则回读 + DRC |
| 铺铜形状不对 | 对象究竟是 pour 还是 fill | reload 后 list/check |
| 位号是 `?` | 位号分配设置、库占位属性 | sch/PCB 位号回读 |
| 板子镜像 | 视图是否翻转 | 真实器件层与朝向 |
