## 可迁移技术点

### DCDC：IN、LX、FB、OUT 各自有位置理由

来源：260915 说明 p3-4、练习5 说明 p3-4、练习7 说明 p3-5。

参数化关系应拆开表达：

- 输入电容靠 VIN/IN，电源先经过电容；输入回路面积单独观察。
- 电感靠 LX/SW，LX 铜短、宽，电感下方保持题目要求的无走线/净空。
- 反馈分压和前馈补偿靠 FB，采样点从输出端取得，远离 LX 噪声区。
- 输出电容靠电感/输出端，地回芯片 GND；大小顺序按当前题目和数据手册。

不要写一个“所有外围靠芯片”的距离分数代替四类关系。验证时分别读取 VIN/LX/FB/OUT 的
焊盘、器件、轨迹与禁布区。

### Near pin：位号与具体电源脚一一对应

来源：练习3 说明 p4、练习4 说明 p3、练习5 说明 p4；对应原理图上的 Near pin 标注。

同值电容不能按最近芯片中心分配。先建立 `电容 → 电源脚/电源域` 表，再以真实 pad center
计算距离和可布通路径；移动 MCU 或旋转后重新计算。验证者故意把两只相同 100nF 对调到错误
电源脚时，应由对应关系和实际铜路径发现，而不是靠 BOM 或总距离放行。

### 开尔文连接

来源：练习6 说明 p5，“电流感应放大器的 IN+/IN- 引脚，使用开尔文走线连接到电流采样电阻”。

IN+、IN- 各从采样电阻对应焊盘独立引出，不在载流主干的任意中间点取样。样例参数至少包含
采样电阻两个 pad、载流入口/出口、sense P/N 端点和禁止共享的主干段；回读时检查两根 sense
线的首端确实落在两个焊盘末端。

### 多单元 MCU

来源：练习5 `原理图.pdf` 第 1 页，同一 STM32F405RGT6 在图上分成功能/电源单元展示。

页面上出现两个符号块不等于 BOM 有两个 MCU。读取 library identity、uniqueId/实例关系和所有
单元 pin，合并成一个器件的连接黄金表；PCB 只应有对应的一个 footprint。这个样例先保持
`source-only`，直到使用真实 EasyEDA 多单元符号回读确认字段形态。

### 传感器开槽

来源：练习3 说明 p4（AHT20 周边开槽建议）；练习7 说明 p4（CO2/温湿度模块无铜槽，槽宽
≥1mm、距板框 ≥1.5mm且不挖断板框）。

区分三件事：机械槽、无铜区域、器件禁放。`pcb slot` 产生机械切口，`pcb region` 表达禁铜/
禁放；两者不能互相冒充。槽尺寸、板框剩余强度和传感器换气方向分别回读。

### RF 与天线净空

来源：练习3 说明 p3-4；练习7 说明 p3、p5。

- 练习3 的离散 RF 同轴路径要求顶层短直、无换层，并以地过孔包围；这是走线屏蔽示例。
- 练习7 的 ESP32 模组天线要求禁止元件与铺铜、多层禁铜、天线底部不走线；这是天线体积净空。

二者不能合并成“有一个 keepout 就通过”。回读每个铜层的区域规则、天线下轨迹和元件重叠。

### 封装禁放类型

来源：260919 说明 p3 的 LCD（禁止“元件”）；练习7 说明 p3 的 ESP32 天线（禁止“元件与铺铜”）。

LCD 身体区允许保留题目未禁止的电气行为，天线区需要更强的全层铜/走线限制。创建规则区时
显式列出 `no-components`、`no-pours`、`no-wires`、`no-inner-electrical` 等实际类型；不要把
默认 region 规则当作两种场景的共同答案。

### 允许出板的题目例外

来源：练习3 说明 p4（仅 RF 同轴连接器）、练习4 说明 p4（仅旋转编码器）、练习6 说明 p4
（仅 CN1-CN3）、练习7 说明 p4（仅旋转编码器外形丝印）。

例外属于具体位号/外形和具体题目。参数中写 `allowedOverhangRefs` 及允许的方向/外形，不关闭
整板越界检查。260919 没有此类例外，不能从历史题迁入。

## 使用方式与验证

1. 先选一个技术点，不加载整套历史题到当前计划。
2. 把来源页里的数值和例外抄入当前参数记录；当前数据手册或机械图冲突时单列，不自行放宽。
3. 用当前工程真实符号、封装、pad、层和规则重新计算。
4. 由独立 Agent 只拿原始题目、当前样例和实际输出复核。错误注入可使用：Near pin 对错脚、
   开尔文从主干中点取样、天线只做顶层禁铜、允许出板例外扩大到所有连接器。
5. 现场通过后只提升该技术点和该工程实例的状态，不把整套题标成黄金答案。
