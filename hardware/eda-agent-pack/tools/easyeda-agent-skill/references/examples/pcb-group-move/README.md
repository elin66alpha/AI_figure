# 已有相对布局的完整组移动

本例对应 LG-01（平移）与 LG-02（整组旋转）：保留已布好的内部关系，只改变整个组的位置
和朝向。它是开发验证场景，可关联多条自动测试；不是完整电路设计或整板布通的证明。

## 来源、起点与参数

来源为 2026-09-23 用户的组合移动需求。公开输入为手工定义的合成几何，所有 `fixture-*`
身份均是虚构测试 ID；封装尺寸不是实测器件选型。不得将生成的 Apply 用到真实工程。
迁移到现场时必须用 fresh `pcb dump --include-copper` 替换几何与 PID，重新确认所有权。

- [board.json](board.json)：`pcb dump` 结构的离线 fixture；二层、七件、无铜、精确矩形板框。
  不是 `pkg/pcbmodel.Board` 格式，后者不能直接喂给 CLI `--board`。
- [layout.json](layout.json)：现有 `pcb layout-plan` 参数；U1 为 anchor，完整成员固定为
  `U1/C1/C2/R1/D1`；J1/H1 不可移动。C1/C2 属于 U1 的供电脚，R1 属于输出，D1 属于 R1
  的负载端。本例用这些关系检验几何保持，不宣称已经实现电气连接。
- 单位 mil、y 向上、写入 footprint anchor。U1 bbox 中心与 anchor 不同；C2/D1 原始角度
  为 90°。dx=150、dy=100，分别比较整体 0° 和 90°。这些是移动参数，不是成功布局答案。
- 无铜版本只验证几何与队列。带内部铜、既有外部铜、位号/3D 绑定、全网通道另建场景，
  不用 `copperPolicy: ignore` 绕过。新协同 solve 的内部铜 Apply 尚为 `unsupported`。

## 独立期望

令原 U1 anchor 为 A，偏移为 d，整体旋转为 R；每个成员 anchor 和 pad 坐标 P 都须满足
`P' − (A+d) = R(P−A)`。成员间距离、相对角度、pad ID/编号/网络/层保持；bbox 所有角点
同步变换。J1/H1 原始几何保持，Apply 只包含五个成员的 modify 和 save。原始输入不被修改。

0° 时所有成员向量不变；90° 时向量 `(x,y)` 变成 `(-y,x)`。验收不抄候选坐标作标准答案。
独立成员表必须来自需求：若漏掉 C2，算法仅凭缩小后的组无法知道业务遗漏；自动回归须把
独立完整集合与输入、候选、队列分别对账，现场也按同一做法检查。

## 离线步骤

在本目录运行（输出路径可替换）：

```bash
easyeda pcb layout-plan --board board.json --from layout.json \
  --module established-group --candidates 3 --out /tmp/pcb-group-move
```

输出 `manifest.json`、两个候选 JSON、SVG 与 `.apply.json`。先比较两个候选的上述不变量，
再看图的成员关系与板边；本例没有 Router 需求，不计算导通路径。**Apply 仅供离线审阅**，
输入没有真实工程绑定；现场要从实测数据重新生成。

源码仓库的自动回归入口（安装版 Skill 无需依赖测试源码）：

```bash
go test ./internal/app -run '^TestPCBEstablishedGroupScenario$' -count=1 -v
```

它使用此处同一组输入核对宿主候选、公共组变换和 Apply 成员集。迁移时先修改偏移等自由
参数，再计算；不能只复用本例输出坐标。自动用例提供可重复规则断言，开发场景还须保留
前后预览、实际命令、失败修法和现场证据。

## 现场步骤与错误修法

现场范围是 ceshi 专用无铜测试组，当前尚未执行本例：

1. fresh health 核对目标工程/文档，保留原始 dump、完整成员/固定对象、规则、DRC 与来源哈希。
2. 将当前组内位置固化为基线，明确每个外围 owner；按实测替换此例参数并生成候选。候选
   与输入/独立成员表不一致就修源数据或工具，不现场逐件补移动。
3. fresh 来源对账后 typed Apply，只移动当前候选声明对象。发生部分成功时先回读并保留
   journal，从实际状态重算或按原参数恢复，不重复重放旧 PID 队列。
4. 按 [Layout 两轮自检](../../pcb-layout.md#layout-观察视图与连续两轮自检) 检查，第二轮保存、
   重载、新 dump、新整板预览；核对所有成员 anchor/bbox/pads、位号/绑定及每个未修改对象。
   实际量化容差依据宿主回读记录，不能用大容差吞掉少移动成员或旋转中心错误。
5. 保存证据后按原参数恢复测试对象，并保存重载核对清理范围。恢复/清理未完成要显式保留待办。

预期负例：绕 bbox 中心旋转、只挪核心、漏外围、写入固定件、缺测、带铜只动器件。发现
任何一项不能称本例通过；修复后回归并重新计两轮。布局确认前仍不写跨模块普通走线。
