### 已踩过的坑（务必遵守）
1. **每条命令都带 `--project 8c5d… --doc <页 UUID>`**。`--doc` 会切换前台文档；只带 `--doc` 的原理图写入在 PCB 前台时会预检失败（"geometry read failed"）。
2. **`doc reload` 会重新生成 PCB 图元 ID**。每次 reload 后先 `pcb dump`，再用新 ID；旧 ID 返回 "primitive ID not found"。未 save+reload 的 dump 可能是旧数据。
3. 换面要用数字：`pcb modify --patch '{"layer":2}'`（1=正面，2=背面）。字符串 `"BOTTOM"` 会被静默忽略（`applied: []`）。换面和旋转放在同一 patch 时旋转会被丢弃，必须分开写。
4. PowerShell 变量不区分大小写（`$P` 等于 `$p`），参数数组不要和循环变量同名。不要把 easyeda 输出接到 `Select-Object -First N`，那样进程可能在写文件前被杀掉。
5. 从 Python 生成的参数文本要去掉 `\r`，否则最后一个数值参数会被拒收。
6. `pcb antenna-keepout` 在 v1.8.0 有 bug（"Region name is only supported with follow-rule"），天线禁布区已用 `pcb region create` 手工建好，**不要再运行它**。
7. `pcb view-side` 需要 `--side top|bottom`。
8. 原理图 `sch replace` 会保留旧导线；新符号引脚不同时，旧线会穿过新引脚，**静默**连错网络。改原理图后一定要逐脚对比网表。

- 还没有建网络类（net class），可按第 6 节的线宽需要自行创建。

## 6. 建议线宽（2 层，1 oz）

| 网络 | 建议线宽 | 理由 |

| VBUS_USB、$1N222、VBUS_CHG | ≥ 0.5 mm | USB 输入，充电 0.33 A + 系统负载，峰值约 1 A |

| SYS、VBAT | ≥ 0.5 mm | 电池和系统主干 |
| 3V3：U3 → C16 → U1.3 主干 | ≥ 0.5 mm（乐鑫建议主电源 ≥ 25 mil） | WiFi 发射峰值约 350 mA |
| 3V3 分支（上拉、麦克风、LED） | 0.25 mm | |
| 3V3_AMP | ≥ 0.4 mm | 功放峰值约 0.4 A |
| SPK_P / SPK_N | ≥ 0.4 mm，两根并行 | 无滤波 D 类输出 |
| USB D+/D−（*_CONN 与 R6/R7 后） | 差分对，0.25 / 0.15 mm，等长 | USB 2.0 全速 12 Mbps，对阻抗不敏感，但要短、少过孔、下方有完整 GND |
| 其他信号 | 0.2–0.254 mm | |

## 7. 布线顺序与要点

1. **充电功率回路（背面底部）**
   - SW 节点：U2.1 ↔ L1 上焊盘，最短、最宽。
   - 输入回路：C6 ↔ U2.8(IN) 与 PGND/EP 形成最小环路。
   - SYS：L1 下焊盘 → C7 → U2.7。
   - U2 的 EP 下方打 4–6 个 GND 过孔，兼作散热。
   - SW 节点下方另一面（正面，在电池区内）保持完整 GND，不要走信号。
2. **USB 输入**：J1 VBUS ×4 → F1 → R8 → VBUS_CHG（C6、D4、U2.8）。CC1/CC2 → R4/R5 → GND。
3. **USB 差分对**：J1 D+/D− 两对引脚就近并联 → D1/D2（ESD 焊盘要在线上，不要拉支线）→ 向上经 J2 插针与上下拉电阻排之间约 1.8 mm 宽的通道 → R6/R7 → 换到正面 → U1 右列 USB 脚。
   - 尽量只在 R6/R7 处换一次层，换层处旁边加一对 GND 回流过孔。
   - 注意 J2/J3/J4 的 2.54 插针穿板，背面也占位。
4. **3V3**：U3（背面左上）→ C16 → 过孔 → 正面左侧 C2/C3 → U1.3（左列最上）。
   - 去耦电容 C2/C3 要放在过孔和模块引脚之间，让电流先经过电容再进模块。
   - 再从这里分支到其余 3V3 负载。
5. **功放**：
   - U7(OUT) → C4 → U5.6(VDD)，C5 紧挨 U5 的 VDD/GND。
   - U5 的 EP 下方打 GND 过孔。
   - SPK_P/SPK_N 并行短线 → J3 插针（正面插座，插针穿到背面，可直接在背面连）。
   - I2S_BCLK、I2S_WS、AMP_DIN、AMP_CTRL 从 U1 底排过来，约 15 mm。
6. **麦克风**：MIC_CLK、MIC_DATA 从 U1 底排到右上角 U4，约 20 mm。
   - 两根并行，远离 SW 节点、SPK 和 USB。
   - U1 上 MIC_DATA(12) 与 SYS_ADC(13) 相邻，引出后尽快分开。
   - U4 的 VDD 用 C13（背面正下方）就近去耦。
7. **其余慢速信号**：
   - EN：C15/R9/TP1。
   - 启动脚：BOOT_GPIO2/R10，BOOT_GPIO9/R12/TP3。
   - REC_KEY：R18 → J4。U1 引脚在左列，J4 在右侧，需要跨越整个模块下方，属正常。
   - LED：R11 → D3 → R13。
   - SYS_ADC 分压。
8. **铺铜**：两面都铺 GND，全板打缝合过孔（间距 ≤ 5 mm，模块四周和天线区边缘加密）。
   - 天线禁布区内两面都不能有铜。
   - 背面模块正下方尽量是整块 GND。
   - 铺铜后要 `pcb pour-rebuild`。

可用工具：`pcb route-critical`、`pcb route-short`、`pcb track`、`pcb via`、`pcb via-hop`、`pcb diff-pair`、`pcb pour` / `pour-fit` / `pour-rebuild`、`pcb via-stitch`、`pcb autoroute`（Freerouting）。自动布线结果必须人工核对：SW 节点、USB 差分对和天线区都不能交给它随便走。

## 8. 验收标准（交回用户前）

- DRC：0 个间距、短路、region 违规；"未连接"为 0。
- 网络完整：逐网络核对所有焊盘已连通（`pcb net-path` 或 dump 对账）。
- 天线禁布区、麦克风圈、电池区三个 region 仍在且无违规。
- 按 skill 要求执行：save → 有界 reload → 新 dump → 新渲染，正面和背面各截一张图；连续两轮自检无须修改，再交给用户。
- 布线后整理丝印位号。背面上下拉电阻排和 TP 附近目前有重叠，丝印不要压在焊盘上，也不要落到电池区内的焊盘附近。

## 9. 已知遗留问题（不是布线 Agent 造成的，可在报告里说明）

1. **DRC 的 "Netlist Error"**：EasyEDA 报"原理图和 PCB 网表不一致"，但逐焊盘对比 48 个器件的网络，结果 0 处不同，再次 import-changes 也没有变化。原因未明，原理图里也查不出差异。
2. **原理图 J4 两条 pin-exit-direction 错误**：已存在很久，是导线出脚方向的绘图问题，不影响连接。
3. **RF**：电池上沿离天线区约 14 mm（乐鑫建议 15 mm 内无金属），打样后需实测 WiFi 距离。备选方案是换成同封装、引脚兼容的 ESP32-C3-MINI-1U，接外置天线。
4. **J1 定位脚在电池下方**：装配时要剪平脚尖，并贴绝缘胶带。
5. **J3/J4/J2 立式 2.54 排针约 8.5 mm 高**：比 6 mm 厚的电池还高，外壳要留出空间。
6. **R3 精度**：3.0 kΩ 对应的充电电流约 0.33 A，但手册只标定了 2 kΩ（0.5 A）这一点，打样后需实测充电电流。
