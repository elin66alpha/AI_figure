# 走线转角修正检查点

用户明确要求：全板走线不使用 90° 转弯，粗电源线同样适用，采用折线或曲线。

## 已修改并保存回读

- 原有 15 处直角转弯改为 45° 折线；焊盘附近的裁切受实际铜尺寸约束，保持焊盘接触。
- 6 处垂直分支改为 120° 钝角汇合，避免仅斜接产生锐角；部分过渡已圆弧化。
- 修正 USB_DP_CONN 一处折返锐角。
- 现场实际回读：129 段直线、20 段圆弧、16 个过孔。48 个器件及三个 region 的完整数据与转角修改前一致。

## 验证事实与范围

- `after-rounded-branches-angle-audit.json`：同层同网直线的端点、内部 T 形交接、交叉处，90° 为 0；圆弧端点的切线交接无直角或锐角。
- `check-rounded-branches.txt`：锐角 0、悬空端点 0、浮铜线岛 0、重复线段 0、过孔压焊盘 0。工具另报 24 个自由角度提示，主要来自 120° 分支及其过渡；这是偏好 45° 网格的提示，不能将其写成全部走线都在 45° 网格上。
- `drc-rounded-branches.json`：间距、短路、禁布区错误均为 0。全板仍有 142 条未连接、2 条 USB 长度差提示及 1 条原有 Netlist Error，整板布线未完成。
- `corner-connectivity-verification.json`：以原生 DSN 的实际焊盘多边形/圆和新鲜直线、过孔、圆弧建立接触图；圆弧按不超过 1° 采样，读回舍入容差 0.03 mil。七组已布关键网络的所有指定焊盘同属连通分量；8 个散热过孔逐个连到所属 EP，并有双面导线接触。此项仅证明连通，不证明焊盘的访问顺序或 USB 路径长度。
- 电源主路、功放主路的圆弧修改前 typed net-path 均通过。圆弧修改后，MCU 路径的工具测长因粗铜重叠产生多个中心线候选而返回 unknown；不得据此宣称精确路径长度。独立接触图及原生 DRC 用于检查真实铜连接。
- 预览为板框适配的 viewport PNG，不是对象级导出。临时图层显示设置已恢复，260 层的状态回读差异为 0。

圆弧处理动作曾返回 connector timeout，不能根据该动作的 dry-run 数量宣称成功。随后已成功保存、重载、读取实际 20 段圆弧并完成上述检查，最终以真实回读为准。

## 接续工作

1. 所有后续候选和最终保存回读必须再次检查转角，包含粗电源线。
2. 现有路由器候选是转角修改前生成的离线资料，未导入 PCB；必须重新导出当前带圆弧的工程，保留关键铜，再生成并核查候选。
3. 原生 DSN 导出存在已查明的数据问题：禁布区坐标额外偏移 5 mil、网络类用单引号导致绑定不正确、过孔同时被导出成 image pin 和 wiring via。离线修正参数及依据见 `prepare_router.py` 和 `router-input-audit.json`；不能直接把原始导出交给路由器后盲目导入。
4. USB 等长、其余信号、电源主干、GND 铺铜与缝合、丝印整理及整板验收仍待完成。保持器件位置、角度和装配面不变。

最新保存回读为 `corner-final.json`，转角复核为 `corner-final-angle-audit.json`；原生备份为 `corner-verified.epro2`。这些是布线过程检查点，不是生产定版。
