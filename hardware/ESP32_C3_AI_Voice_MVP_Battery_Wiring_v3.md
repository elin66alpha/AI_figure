# ESP32-C3 AI 语音设备：自制 PCB 硬件方案

> 修订：2026-09-29。文件名沿用 v3，内容已改为“不使用开发板或功能模块，直接在自制 PCB 上焊接芯片及外围元件”。
> 目标：1S 3.7V 软包锂电池供电、USB-C 充电与烧录、机械键盘轴按住录音、Wi-Fi 联网、单声道语音播放。
> 最新选择：天线经同轴线引至身体外部；麦克风改为 TDK ICS-43434，直接接现有 3.3V 与 I2S，不增加辅助芯片；采用 16kHz 本地与网络采样；仅作现货样机料，厂家已标 EOL。
> 设计优先级：在以上功能选择下控制总成本、元件数量和装配难度。默认不追求 3W 满功率；保留 MCU 裸芯片方案，不使用功能模块。调试 LED 和两个轻触按钮量产可不焊（DNP），但保留焊盘。
> 本文是选型与原理图设计依据，不是已验证的生产原理图。元件值中的“起点/预留”须经原理图核算和首板测试后定版。
> 本次沿用现有固件的音频、按键和状态灯 GPIO。`AGENT.md` 中 SuperMini 的供电、板型和模块说明属于旧原型；定制板硬件以本文为准，网络协议与业务状态机沿用现有设计；新板的音频增益、功放 CTRL 及低压策略须按第 9、10 节适配，不代表旧固件已验证兼容。

**采购表已排除所有平台代购。电气检查发现原方案有问题，下面为修订后的样机方案，尚不能直接作为量产图纸。** 普通现货只说明能买到，不能代替电气兼容和生命周期检查。

| 元件 | 本次处理 | 检查结论 |

| ESP32-C3FH4 / C2858491 | 保留 | 乐鑫裸芯片，内置 4MB Flash；普通现货，非代购；仍须外部 40MHz 晶振和 RF 网络 |
| 麦克风 | 换 ICS-43434 / C5656610 | 替换原代购 DMM；3.3V、I²S，无新增辅助 IC；16kHz 模式标称 64dBA；厂家 EOL，仅用于当前现货样机 |
| NS4168 / C910588 | 保留国产候选，修改供电 | 原 SYS_SW 直供不能保证输入电平；改与 MCU 共用 3V3，限输出功率，并验证 LDO 电流与散热 |

| DW01A + FS8205A | 本版主板删除 | 指定康胜电池的厂家手册确认内置 PCM；避免重复保护。不能因此改用无保护裸电芯 |
| 电源开关 | 换 SS12D10G5 / C7431054 | 首韩单刀双掷、2A 等级候选；旧小开关未完成负载能力验证。新开关仍需确认低压直流通断及浪涌寿命，后焊 |
| 1µF 电容 | 换风华 0603X105K160NT / C89188 | 原三星 C15849 普通现货为 0；新料 0603、16V、X5R，价格略低 |
| 供电 ADC | 恢复两个电阻和一个电容 | 必须能测到供电电压，才能实现提前停止工作；不能依赖 LDO 掉压自动安全关机 |
| 其余器件 | 保留现货料 | ESD 钳位、储能电容纹波、晶振负载及装配尺寸仍需按下文验证 |

### 量产前未关闭的问题

1. **麦克风生命周期与数字输出保证值**：ICS-43434 厂家为 EOL；SD 的最坏输出电平与 C3 的保证输入阈值不能仅靠手册闭合，详见第 7 节。当前满足直接现货打样，不能描述为长期量产料或全温保证兼容。
2. **共用 3V3 的功率与稳定性**：首板按小音量验证；热核算、音频瞬态和较大输出电容下 LDO 稳定性未完成，见第 6 节。
3. **欠压停机与 USB 电流**：本次补回采样和工作策略，但固件尚未实现，且软件休眠不是硬件断电；USB 输入也没有自动识别供电额度，见第 5、10 节。

依据：[C3 手册](https://www.espressif.com/sites/default/files/documentation/esp32-c3_datasheet_en.pdf)、[ETA6002 手册](https://datasheet.lcsc.com/datasheet/pdf/8efad5a1e38bfd1767a78dc3ee3fef7c.pdf?productCode=C7436031)、[ETA5060 手册](https://datasheet.lcsc.com/datasheet/pdf/f06e40bfaf9d0ccdda290ccd8eaa059b.pdf?productCode=C7465551)、[NS4168 商品页及厂家手册](https://item.szlcsc.com/978904.html)。

## 2. 修订后的电源架构

```text
USB-C VBUS ── 可断开的充电输入连接位 / 输入保护 ── ETA6002 IN
USB-C D-/D+ ── ESD / 串联电阻 ── ESP32-C3 GPIO18/19

康胜带 PCM 的 1S 电池 PACK+ ── ETA6002 BATT
                      PACK- ── 系统 GND

ETA6002 SYS ── SW1 单刀开关 ── SYS_SW ── ETA5060 ── 3V3
                                 │                   ├── ESP32-C3
                                 │                   ├── ICS-43434
                                 │                   └── NS4168 ── 喇叭
                                 └── 电阻分压 / 滤波 ── GPIO1 ADC
```

- **NS4168 不再直接接 SYS_SW**。共用 3V3 后降低最大音量，换取电平匹配且不增加电平转换芯片；这会增加 LDO 负载。
- ETA6002 有 USB 时 SYS 可达 4.5V；电池模式下 SYS 跟随电池并有路径压降。SYS 不是恒定 3.3V 或 5V。
- SW1 只断负载，关闭时充电及电池 PCM 仍工作，不等于电芯零耗电。VBUS 不得并接 SYS_SW、3V3。
- 保留删除 5V 升压的降本选择；不装独立电量计、USB 转串口、NTC、双刀开关、RGB 或轴体热插拔座。
- 供电分压从开关后的 SYS_SW 取样，避免关机时通过 ADC 向无电的 MCU 回灌；电阻必须常装，不归入调试 DNP。

## 3. ESP32-C3 芯片最小系统

### 3.1 MCU、Flash 与电源

- 选 ESP32-C3FH4，采购时锁定完整料号、芯片修订和对应封装图；不能混用老型号或开发板的封装库。
- 封装内置 4 MB Flash，无 PSRAM；不再额外放一颗 Flash。Flash 内部连接及保留脚按该具体型号处理。
- **芯片没有可直接接 5V 的开发板式电源入口**。电源脚按官方参考电路接 3.3V，并补齐模拟电源滤波和各脚去耦。
- 3.3V 电源设计目标至少覆盖 500mA 供电能力，并留出 Wi-Fi 瞬态余量；本版按约 1A 等级的板级供电目标核算。
- 每个供电区域的陶瓷去耦靠近电源脚，芯片附近预留 10–22µF 储能。不能用远处一颗大电容替代逐脚去耦。
- 裸露焊盘及地脚严格按封装图接地，并布置接地过孔。

### 3.2 晶振、启动和复位

- 外接 **40MHz 晶振**，按乐鑫要求选择频偏和负载电容；两个负载电容不能不经计算直接套用 22pF。
- XTAL_P 串联调试器件及晶振布局按 C3 官方参考设计，最终用射频频偏测试调整。
- CHIP_EN 采用上拉及 RC 延时，10kΩ + 1µF 可作为起点；慢上电或反复开关测试不合格时，采用电源监控复位器。
- RESET 使用常见小型贴片轻触按钮：CHIP_EN → 按钮 → GND；开发版焊接，量产 DNP，仅保留焊盘。
- BOOT 使用同类小型贴片轻触按钮：GPIO9 → 按钮 → GND；开发版焊接，量产 DNP。GPIO9 上拉必须保留。
- GPIO2、GPIO8 是启动相关引脚，本版均预留 10kΩ 上拉；下载时 GPIO8 必须为高，GPIO9 为低。GPIO2 按官方建议上拉。
- GPIO8 使用一颗普通单色贴片 LED：3V3 → 限流电阻 → LED → GPIO8，低电平点亮。量产可同时不焊 LED 和其专用限流电阻；GPIO8 独立启动上拉必须保留。
- CHIP_EN 的 RC、启动上拉、电源去耦不是调试件，不能随按钮或 LED 一起删掉。

### 3.3 外置天线：本版采用

**可以把成品天线引到身体外部，主 PCB 不再绘制天线辐射体。** 塑料/布料外壳通常不要求天线通过开孔接触空气；金属、导电涂层、电池及天线附近物体更影响效果。外置有助于远离内部遮挡，但仍需整机测试。

```text
ESP32-C3 RF 引脚
  → 芯片 RF 匹配网络
  → 50Ω PCB 馈线
  → 板端 I-PEX MHF I / U.FL 对应规格座
  → 50Ω 细同轴转接线
  → 固定在身体外壳上的 SMA 母头（带螺母）
  → 外置 2.4GHz SMA 公头成品天线
```

- 首板参考天线选 **Taoglas GW.11.A113**，2.4GHz、50Ω、普通 SMA 公头、约 84mm 长；它是有数据手册的验证参考，不代表最低价采购件。
- 量产可换有规格书的较低成本 2.4GHz 天线，但必须复测阻抗、效率和整机通信，不能保证同样外形就同样性能。实际长度按造型选择，不盲目追求高增益。
- “IPEX”不是唯一接口尺寸。板座、同轴插头必须锁定同一系列；SMA 与 RP-SMA 的中心针孔配置也不同，本方案统一普通 SMA，采购图纸逐一核对。
- 同轴线只按所需长度选，首板可按约 10–15cm 评估；实际由主板与安装点距离决定。线越长损耗越大，不盘绕在电池旁，不夹伤、不急弯。
- 外壳承担天线的拉力和扭矩，同轴线加应力释放。板端微型 RF 座不作为用户反复插拔接口。
- 若外露杆状天线影响造型，也可将成品 FPC 天线放入身体外部的塑料耳朵/尾巴等非金属结构中；届时使用对应天线规格，不能把裸 FPC 当成耐磨外壳表面。
- 外置天线仍需芯片端 RF 匹配与短的 50Ω 馈线；普通 GPIO 或普通导线不能代替 RF 输出与同轴线。不并联 PCB 天线，避免未终端分支。
- 首板在装好外壳、天线和电池后测 RSSI、丢包、不同朝向及握持状态。量产采用最终天线/线缆组合验证射频性能与适用的发射限制。

参考：[GW.11.A113 产品页](https://www.taoglas.com/product/gw-11-a113-2-4ghz-2-3dbi-screw-mount-dipole-antenna/)、[乐鑫 RF 设计指南](https://docs.espressif.com/projects/esp-hardware-design-guidelines/en/latest/esp32c3/schematic-checklist.html)。

## 4. 单 USB-C：充电、烧录与日志

| 信号 | 板上连接 |
|---|---|
| VBUS | 经可断开的充电输入连接位及输入保护接 ETA6002 IN |
| GND | 系统 GND，即保护后的 PACK- |
| CC1、CC2 | 各自独立通过 5.1kΩ 接 GND，不能短接成一个 CC |
| D- | GPIO18，按官方建议预留串联电阻并放置低电容 ESD 器件 |
| D+ | GPIO19，同上 |
| 屏蔽壳 | 预留接地/EMC 网络，结合整机设计定版 |

- 使用支持 USB 2.0 数据的连接器；同名正反插 D+/D- 焊脚正确汇合，走线避免长支叉。
- ESP32-C3 自带 USB Serial/JTAG，本版不需要 CH340/CP2102。
- USB 差分线按 90Ω 设计，ESD 器件靠接口，串联电阻靠芯片，预留值参考官方建议。
- 两颗 CC 下拉仅声明受电端，**不代表已经获准从任何 USB 口取 1.5A/3A**。输入限流应与主机枚举或 Type-C 电流能力检测结果匹配。
- 当前没有自动电源能力识别及精确输入限流。电脑烧录时断开充电输入连接位，由电池供电；正常充电使用已确认能力的 5V 电源，具体限制见第 5 节。
- 关闭主开关时默认只充电；烧录需开启主开关。验证关机插 USB 时数据脚不会造成异常反向供电。
- 保留 UART0 测试点：GPIO20/RX、GPIO21/TX、GND，以及 EN、BOOT；外部工具只用 3.3V 逻辑，避免其电源输出与板上电源并联。

## 5. 充电、电池与保护

### 5.1 ETA6002E8A

- 4.2V 满充的单节锂电充电器；IN 工作范围 4.4–5.5V，绝对最大值 6V。输入不能接快充高压；输入保护须核对实际钳位和浪涌，不只看 TVS 标称电压。
- 典型应用：IN 10µF、SYS 22µF、BATT 1µF，SW 到 SYS 用 2.2µH 电感。2026-09-29 经用户同意，L1 已改为标准 EDA 库的 FXL0618-2R2-M（C524593）：额定电流 7A、饱和电流 8A，DCR 典型 28mΩ、最大 35mΩ，约 7.0×6.6×1.6mm。依据归档手册 `eda-design/FXL0618-datasheet.pdf` 第 2、6 页；饱和与温升仍按实际峰值和散热条件核算。
- ESOP8 引脚：1 SW、2 PGND、3 NTC、4 STAT、5 ISET、6 BATT、7 SYS、8 IN、9 裸焊盘 AGND；AGND 与 PGND 按参考布局连接。
- ISET 按 `I_BAT(A) = 1000 / R_ISET(Ω)` 设置。原 2kΩ 对应 500mA，手册范围可到 550mA，超过本电池 500mA 最大充电值；本版先用 **2.49kΩ、约 400mA**，复核电阻误差、芯片误差和全温最大充电电流必须不超过 500mA。
- NTC 脚接地禁用检测，不装电池 NTC；这也意味着没有电芯温度监测，不可把芯片自身过热保护当作电池温控。
- **ISET 不限制“充电 + 系统”的总 USB 电流；1A 自恢复保险丝也不是 USB 精确限流器。** 本轮不增加 USB 供电识别芯片：样机正常充电使用明确允许所需电流的 5V 电源，按 5V/2A 电源和线材验证；不能宣称兼容任意电脑口边充边播。
- 电脑烧录采用电池供系统，并断开 VBUS 到 ETA6002 的充电输入连接位，只保留 USB 数据连接及公共地；连接位纳入原理图和 0Ω 预算。若要求电脑口自动边充边用，需要另行实现供电额度检测/输入限流并重算成本。

依据：[ETA6002 厂家手册](https://datasheet.lcsc.com/datasheet/pdf/8efad5a1e38bfd1767a78dc3ee3fef7c.pdf?productCode=C7436031)。

### 5.2 指定电池自带 PCM，主板不重复装保护

采用 C3036738 对应的康胜 **LP-503450-3.7V-1000mAh-PCM** 成品电池。厂家资料列明：满充 4.2V、正常放电终止 3.0V、最大充电 0.5C（500mA）、最大持续放电 1C（1A），尺寸上限约 5.5×34.5×53mm，带线及 PCM。

- 电池 PACK+/PACK- 直接进入主板电池接口，PACK- 为系统 GND。主板删除 DW01A、FS8205A 及其专用外围；不得绕过电池内的保护板。
- PCM 的过放保护约 2.3–2.6V，仅作异常保护，不能当正常放电终止点；需第 10 节提前停机。
- 确认实物完整型号、保护状态、插头系列与极性；禁止在不改原理图/BOM 的情况下换成无 PCM 裸电芯。黄色胶带不能单独证明有保护。
- 全机持续电池电流不得超过 1A，瞬态能力及保护恢复需要测量；不把 PCM 的数安培过流门限当作允许工作电流。
- 无 NTC 的本版按厂家给出的充电温度范围 10–45℃使用；结构需避免电芯被功放/LDO 加热。

依据：[电池商品页](https://item.szlcsc.com/mro/3588023.html)、[康胜规格书](https://atta.szlcsc.com/upload/public/pdf/source/20220902/C2C71EF6EACFFD7C6DA463C88834D37F.pdf)。

## 6. 3.3V LDO 与功放共用供电

### 6.1 ETA5060V330S8F

SOT89-5 引脚：1 NC、2 GND、3 EN、4 IN、5 OUT。IN/EN 接 SYS_SW，OUT 接 3V3，NC 悬空；按手册及负载验证放置输入、输出陶瓷电容。本版各预留 10µF，麦克风和 MCU 独立近端去耦。

- 1A 是器件能力，不能据此承诺小板持续输出 1A。压差 140mV 为 1A 条件下典型值，没有可直接用作欠压阈值的最坏保证。
- 按 `P_LDO ≈ (SYS_SW - 3.3V) × I_3V3` 核算。USB 下输入 4.5V、总电流 0.5A 时约耗散 0.6W；手册 SOT89-5 的 77℃/W 仅作参考，板上铜面积、封闭外壳和电池附近温度须实测。
- 功放也走此 LDO，首板从约 **0.3W 语音输出目标**开始，在 Wi-Fi 发射同时测峰值与温升；0.3W 是调试目标，不是已经验证的输出保证。不能保留原高音量配置直接运行。
- 输出挂有 MCU 储能、功放 100µF 等负载电容；厂家明确描述的稳定电容范围是 1–10µF，**不能直接宣称整板的大电容网络已稳定**。冻结前确认厂家允许范围并测启动、负载阶跃和振荡。失败则重新选国产稳压方案并更新成本。

### 6.2 为什么修正 NS4168 的供电

NS4168 手册给出的数字高电平门限为 `0.7 × VDD`。原接 SYS 时，SYS=4.5V 要求 ≥3.15V，而 C3 在 3.3V 下保证 VOH 仅 2.64V；即使典型样板能出声，也不能算规格闭合。功放现在接共同的 3V3，输入门限约 2.31V，消除这处跨电源电平问题。

NS4168 手册首页/电气表写 3.0–5.5V，而极限参数写到 5.0V，存在冲突；本方案选 3.3V，不用 5.5V 上限作依据。手册所说 **3.6V、4Ω、1.2W 是 THD+N=10% 条件**，不能标为本版干净输出功率。

功放近端采用 1µF 陶瓷和 100µF 储能候选；RVT6.3V100M5X5 的纹波额定值和 ESR 要与实测音频电流核算，不因容量相同就视为已通过。布局使功放电流回路远离麦克风与 RF。

依据：[ETA5060 厂家手册](https://datasheet.lcsc.com/datasheet/pdf/f06e40bfaf9d0ccdda290ccd8eaa059b.pdf?productCode=C7465551)、[NS4168 厂家手册入口](https://item.szlcsc.com/978904.html)。

## 8. NS4168：国产 I²S 功放接线

NS4168 为 ESOP-8-EP 裸芯片，不与 MAX98357A 引脚兼容；本版工作电压为共同的 3V3。

| 物理脚 | 信号 | 连接 |
|---:|---|---|
| 1 | CTRL | GPIO10；100kΩ 下拉，启动默认关闭 |
| 2 | LRCLK | GPIO5 |
| 3 | BCLK | GPIO4 |
| 4 | SDATA | GPIO7 |
| 5 | VoN | 扬声器负端，不接地 |
| 6 | VDD | 3V3，按第 6 节验证近端电容 |
| 7 | GND | 系统 GND |
| 8 | VoP | 扬声器正端，不接地 |
| EP | 裸露焊盘 | 按厂家封装图连接、铺散热铜和过孔 |

CTRL 低于 0.4V 关断，高于 1.5V 选择右声道。GPIO10 高低控制；TX 向右 slot 写数据，或左右写同一单声道数据。播放前先送零、再开启，停止后排空尾音再关断。

扬声器输出为 BTL Class-D；两根线成对、短且远离麦克风和 RF，示波器用差分方式测量，不能将接地夹接到 VoP/VoN。

### 9.1 机械轴录音键

- 使用常开、无锁定的机械键盘轴，两个电气触点分别接 GPIO3 和 GND；按住录音、松开发送，原有低有效逻辑保持。
- 优先静音红轴或普通红轴，减小轴体点击声进入麦克风；普通红轴触底仍会产生机械声。青轴可用，但清脆点击声和释放声可能被录入。
- 一个独立按键不需要键盘矩阵、扫描芯片或防冲二极管。首版采用直接焊接轴体，不加热插拔座；内部上拉加软件消抖，必要时预留外部上拉位置。
- 封装按实际 MX 类 3 脚/5 脚或其他轴体绘制；电气脚、定位柱孔、轴体中心孔及定位板厚度逐项确认，不能套用轻触开关焊盘。
- 轴体由外壳或定位板承受按压力，麦克风尽量远离轴体和敲击结构。松开时软件保持消抖，避免触点抖动重复触发回合。

| 器件 | 开发版 | 量产版 |
|---|---|---|
| 机械轴录音键 | 焊接 | 焊接，属于用户操作件 |

## 10. 低电压策略：恢复采样，不依赖 LDO 掉压

```text
SYS_SW ── 100kΩ（1%）── ADC节点 ── 100kΩ（1%）── GND
                         ├── GPIO1 / ADC1_CH1
                         └── 100nF ── GND
```

- 分压比 1/2；SYS_SW=4.5V 时 ADC≈2.25V。按 C3 ADC 量程选择衰减并校准，验证电阻误差、峰值电压和开关掉电时的节点放电，不直接把原始 ADC 码当电压。
- 测的是 **系统输入电压**；无 USB 时近似反映电池电压，有 USB 时不能由 SYS 推算真实电池电量。
- 初始按 SYS_SW 约 3.6V 触发低压停止工作，具体门限和迟滞根据负载压降、校准误差及 LDO 最坏压差确定。上电先测供电，再开 Wi-Fi/功放；门限附近不循环重连和播放。
- 低压时关闭功放、无线及音频时钟并进入低功耗状态。这里的休眠是软件停机，**不是电池硬断电**；用户关闭机械开关可断负载。固件及长期欠压泄漏验证尚未完成。
- 指定电池正常放电终止为 3.0V。若软件休眠/故障状态仍会把电池长期拖到该值以下，应补硬件欠压断电并重新计价；内置 PCM 约 2.4V 的异常保护不能替代它。此项完成前不放行量产。

## 12. PCB 布局与首板验证

### 布局要点

- SEUCS2X3V1B 为很小的 DFN0603-2L 封装，不能与英制 0603 阻容尺寸混淆；按 SMT 能力确认可装配性。核对数据线工作电压、钳位电压/电流和走线，目录参数不能代替实际 ESD 测试。
- 22µF/10µF 陶瓷电容按直流偏压后的有效容量核对，100µF 电解按纹波额定与 ESR 核对；更换国产料不是只比较标称容量。

- 首板优先四层板，提高裸芯片 RF 与回流布局成功率。两层板可评估，但必须有对应参考布局和完整地；比较总成本时计入返工和调试，不能仅按板层报价决定。数字、音频、充电与电源按位置分区，保持连续参考地。
- 开关电源热回路紧凑，SW 铜皮面积受控，反馈远离 SW；功放大电流回流避开 ADC 和麦克风区域。
- 充电器和功放预留散热铜及过孔；输入输出电容贴近对应引脚。
- I2S 时钟走线短，预留源端串联阻尼位置，装配值经波形决定。
- 声孔、RF 馈线、外置天线安装孔及同轴走线与外壳尺寸同时检查。

### 打样前与上电检查

1. 原理图 ERC、PCB DRC、逐料号引脚对照；复核电池 PCM 不被旁路、功放 VoN 不接地、VBUS 不直接接 SYS_SW。
2. 先用限流电源代替电池，分支隔离检查充电路径、SYS_SW 和 3V3，再安装/启用负载；检查麦克风供电与时钟。
3. 检查 EN、BOOT、GPIO8 电平及 USB 正反插；确认首次烧录、复位和 UART 救援可用。
4. 测试无电池 USB 运行、电池运行、插拔 USB、关机充电、低电量和保护恢复。无电池且 USB 限流时只要求在功率预算内运行。
5. 在低电池电压下叠加 Wi-Fi 发射和最大允许音量，测电源最低值、纹波、温升、音频失真和是否重启。
6. 测试关机漏电、插 USB 时的系统供电和充电行为，以及麦克风噪声和 RF 干扰。
7. 用受控测试设备验证充电终止、关闭 NTC 检测后的设置、保护阈值和欠压关机；实测续航后再承诺使用时长。
8. 实测轴体按下/释放的录音噪声及机械固定；用不焊 LED、RESET、BOOT 的样板验证治具烧录和正常启动。
9. 验证 16kHz I²S 数据位对齐、频率/时长、麦克风增益、数字电平裕量和联网时 CPU/DMA 余量。
